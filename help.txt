A terminal markdown filter with syntax highlighting.

If no FILE is specified or FILE is '-', read from STDIN.
Multiple files can be specified and will be processed in order.

Usage:
  colored-md [OPTIONS] [FILE...]

Options:
  -h, --help        Display help message
  -m, --man         Display full readme
  -v, --version     Display version information (tip: colored-md --version | jq -r .Version)
  -s, --styles      List available styles and exit

Environment Variables:
  GLAMOUR_WIDTH                Set the rendering width (default: 120)
  GLAMOUR_STYLE                Set one of the predefined styles
  GLAMOUR_OVERRIDE_MARGIN      Override margin (default: 0)
  GLAMOUR_OVERRIDE_MARGIN_CODE Override code block margin (default: 0)

Examples:
  colored-md file1.md file2.md
  colored-md < README.md
  colored-md <<< $'# Hello World\nThis is **bold** text.'
